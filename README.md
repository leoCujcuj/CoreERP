# CoreERP

Arquitectura de microservicios y sistema ERP desarrollado en .NET / C#.

## Estructura de la Solución

- **ClientesAPI**: Microservicio para gestión de clientes.
- **ComprasAPI**: Microservicio para órdenes y gestión de compras.
- **InventariosAPI**: Microservicio de control de inventario y existencias.
- **ProductosAPI**: Microservicio para catálogo y administración de productos.
- **ProveedoresAPI**: Microservicio para control de proveedores.
- **ReportesAPI**: Microservicio de reportería y métricas.
- **SucursalesAPI**: Microservicio para administración de sucursales.
- **UsuariosAPI**: Microservicio de autenticación y gestión de usuarios.
- **VentasAPI**: Microservicio para procesamiento de transacciones y ventas.
- **WebApp**: Aplicación web frontend (ASP.NET Core MVC).

## Requisitos

- .NET 11 SDK (o superior)
- Visual Studio 2025 / Rider / VS Code con C# Dev Kit
